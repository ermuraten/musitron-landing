HTML, CSS, Screenshots und lokal eingebundene Schriftarten; keine App-Quellen, Audiodateien, Zugangsdaten oder Checkout-Funktionen.

Quelle: MusitronTrainer/landing.html und src/landing.css. Schriftlizenzen: assets/fonts/*-LICENSE.txt.

## Aktualisieren

Nach Änderungen im Website-Ordner `git add`, `git commit` und `git push` ausführen. GitHub Pages veröffentlicht `main` aus dem Root automatisch. Erfolg im GitHub-Pages-Lauf und auf der öffentlichen URL prüfen.

Die ursprüngliche Produktseite liegt im separaten App-Projekt unter `landing.html`; Änderungen dort bewusst in diese statische Kopie übertragen. Die hier eingebundenen Schriftarten werden lokal geladen.

`CNAME` gehört zu musitron.mrwhisper.site. DNS: Hostinger CNAME `musitron` auf `ermuraten.github.io` (TTL 300). Apex und Mail-Einträge nicht ändern.

Aktuell keine öffentlichen App-Downloads/Checkout. Dienstanschrift im Impressum noch ausstehend.
